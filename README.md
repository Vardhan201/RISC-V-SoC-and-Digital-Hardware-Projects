# RISC-V SoC and Digital Hardware Projects

A collection of digital hardware design projects focused on Verilog/SystemVerilog, processor architecture, RTL development, and hardware verification.

## About This Repository

This repository documents my journey in digital hardware design and computer architecture as an engineering student.

The goal is to design, implement, simulate, and verify hardware modules while developing practical knowledge of RTL design and VLSI engineering.

## Project Areas

### 1. RISC-V Processor
- RISC-V RV32IM architecture
- Two-stage pipelined processor
- Arithmetic Logic Unit (ALU)
- Register File
- Instruction Decoder
- Control Unit
- Memory Interface

### 2. Bus Interconnect
- AMBA AXI
- AMBA AHB
- Wishbone Bus Architecture

### 3. SPI Peripheral
- SPI Master
- SPI Slave
- Serial communication
- Functional verification

### 4. STAR MAC Unit
- Configurable Multiply-Accumulate architecture
- RTL implementation
- Functional simulation
- Verification

## Technologies and Tools
